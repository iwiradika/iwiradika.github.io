这份测验公平吗？项目功能差异（DIF）实用入门

两名学生对同一道题作答不同，原因不在于他们知道什么，而在于他们是谁。本文介绍这一概念、检测方法，以及它对测评工具开发的实际意义。

I Nyoman Indhi Wiradika
发布于 2026 年 5 月 17 日
阅读约 14 分钟

设想两名小学生：学生 A 是一名在山区农村长大的女生，学生 B 是一名住在海边的男生。老师给他们做了一份生态意识测验。两人对自然环境都有真实且相当的理解，按任何合理标准，他们真正的生态知识都是相同的。

接着出现了第 12 题：“为什么保护红树林对沿海社区很重要？”学生 B 凭直接经验自信而详细地作答；学生 A 却答不上来——不是因为她缺乏生态意识，而是因为她生活的环境里根本没有红树林。

这道题测到的不是能力差异，而是对情境的熟悉程度差异。这正是项目功能差异（Differential Item Functioning，DIF）分析要检测的核心问题。处理好这个问题，是编制在各群体间都真正有效的测评时最重要的步骤之一。

DIF 到底是什么？

当来自不同群体、潜在特质水平相同的受测者答对某题的概率仍然不同时，就出现了 DIF。关键限定是“特质水平相同”。DIF 不只是群体平均分不同——那可能反映真实的能力差异。DIF 关心的是：在控制能力之后，题目在各群体中是否一致地发挥作用。

DIF 关心的不是各群体得分是否不同，而是题目对所有群体测量的是否是同一件事。

用 IRT 的话说，如果某题的项目特征曲线（ICC）在两个群体中不相同，就说该题存在 DIF：即使能力相同，一个群体的成功概率也高于另一个。DIF 分析中的两个群体有固定的名称：

  • 参照组：多数群体或基准群体（例如男生、较高年级）
  • 焦点组：表现受到审视的群体（例如女生、较低年级）
影响（不是 DIF）
  • 各群体平均分不同
  • 反映真实的能力差异
  • 各群体的 ICC 曲线平行
  • 题目功能正常
  • 无需修改
项目功能差异
  • 能力相同时群体之间仍有差异
  • 反映题目本身的偏差
  • ICC 曲线分离或交叉
  • 题目测到了额外的东西
  • 审查并视情况修改题目

通过 ICC 看 DIF

项目特征曲线是可视化 DIF 最直接的方式。对于功能正常的题目，能力 θ = 1.0 的受测者无论性别、年级或背景如何，答对的概率都应相同。如果这一条件被违反，两个群体的 ICC 曲线就会分开。

两种类型的 DIF

DIF 的表现形式并不单一。研究者区分两种形式，这一区分会影响检测方法的选择和结果的解释。

一致性 DIF

一个群体相对另一个群体的优势在所有能力水平上方向一致。在整个能力连续体上，焦点组的 ICC 曲线都发生了平移（更容易或更难）。一致性 DIF 更容易检测，实质含义也更容易解释。

非一致性 DIF

优势方向不一致，会在能力量尺的某一点发生反转。在较低能力水平上焦点组可能优于参照组，而在较高能力水平上情况相反。两条 ICC 曲线相交。

DIF 为什么重要

即使是很小的 DIF，也会在多题工具中累积。如果五道题各自都略微偏向某一群体，对总分的累积影响可能相当大，在高利害考试中尤其如此——微小的分数差异可能决定升级、奖学金资格或录取。因此，DIF 分析不只是技术问题，更关乎测量效度与公平。

检测 DIF 的三种方法

人们已经开发出多种检测 DIF 的统计程序，它们各有不同的要求、假设和统计目标。教育测量研究中最常用的有三种：

经典方法
Mantel-Haenszel
统计量：χ² / ln(α)
不需要 IRT 模型，按观察总分匹配学生。最适合检测一致性 DIF，使用广泛且经过充分验证。
基于 IRT
Lord 卡方
统计量：χ²(df = 2)
比较群体之间完整的题目参数向量。对一致性和非一致性 DIF 都敏感，但需要为每个群体分别拟合 IRT 模型。
回归
逻辑回归
统计量：ΔR² / LRT
对能力与群体归属的交互作用建模，可在一个模型中灵活检测两类 DIF，并自然给出效应量。

实践中，研究者通常先用 Mantel-Haenszel 做初筛，因为它简单、易于解释；然后对被标记或怀疑存在非一致性 DIF 的题目，再用 Lord 卡方或逻辑回归跟进。

实例：在 R 中进行 DIF 分析

下面的例子展示了在 R 中完成一次 DIF 分析的全过程，从数据模拟到图形检查。情境取自教育测量研究：对小学生施测的生态意识工具，以性别作为分组变量。

所需程序包

本教程使用 difR（DIF 检测）、mirt（IRT 建模与 ICC 绘图）和 ggplot2（可视化），均可从 CRAN 获取。

1
安装并加载程序包
R 准备 
# Run once to install
install.packages(c("difR", "mirt", "ggplot2"))

library(difR)
library(mirt)
library(ggplot2)
2
模拟一个生态意识数据集

模拟生成 300 名受测者（男女各 150 名）对 15 道题的作答。通过改变女生组的难度参数，在第 5 题和第 10 题中引入 DIF。

R 模拟数据 
set.seed(2024)

N      <- 300    # total students
n_item <- 15     # number of items

# group: 0 = male (reference), 1 = female (focal)
group <- rep(0:1, each = N / 2)

# simulate latent ability
theta <- rnorm(N, mean = 0, sd = 1)

# item parameters (same for both groups by default)
a_ref <- runif(n_item, 0.8, 1.8)   # discrimination
b_ref <- seq(-2, 2, length.out = n_item)  # difficulty

# introduce DIF on items 5 and 10
b_foc     <- b_ref
b_foc[5]  <- b_ref[5]  - 0.9   # item 5: easier for females (uniform DIF)
b_foc[10] <- b_ref[10] + 0.7   # item 10: harder for females (uniform DIF)

# helper: simulate binary responses from 2PL model
sim_item <- function(theta_vec, a, b) {
  p <- 1 / (1 + exp(-a * (theta_vec - b)))
  rbinom(length(theta_vec), 1, p)
}

resp_male   <- sapply(1:n_item, \(j) sim_item(theta[group == 0], a_ref[j], b_ref[j]))
resp_female <- sapply(1:n_item, \(j) sim_item(theta[group == 1], a_ref[j], b_foc[j]))

data_resp <- rbind(resp_male, resp_female)
colnames(data_resp) <- paste0("Item", 1:n_item)

# sanity check
dim(data_resp)     # should be 300 x 15
table(group)       # 150 male, 150 female
3
Mantel-Haenszel DIF 检测

Mantel-Haenszel（MH）方法是传统的起点。它按总分匹配学生，然后在每个分数水平上比较各群体的题目表现。输出包括卡方检验和 MH 优势比（α），再将其转换到 MH D-DIF 量尺上进行解释。

R Mantel-Haenszel 
mh_result <- difMH(
  Data       = data_resp,
  group      = group,
  focal.name = 1,       # 1 = female (focal group)
  correct    = TRUE     # Yates' continuity correction
)

# Print item-level results
print(mh_result)

# Plot chi-square statistics across items
# Items above the dashed line are flagged as DIF
plot(mh_result, main = "Mantel-Haenszel DIF Statistics")

打印结果显示每道题的 MH 卡方统计量、p 值和 MH D-DIF 值。卡方显著且 |D-DIF| 超过阈值的题目会被标记。D-DIF 的符号表示方向：负值有利于焦点组（女生），正值有利于参照组（男生）。

4
Lord 卡方（基于 IRT）

Lord 卡方为每个群体分别拟合 IRT 模型，并比较完整的题目参数向量。由于它同时比较区分度（a）和难度（b）参数，因此对一致性和非一致性 DIF 都敏感。

R Lord 卡方 
lord_result <- difLord(
  Data       = data_resp,
  group      = group,
  focal.name = 1,
  model      = "2PL"    # 2-parameter logistic
)

print(lord_result)
plot(lord_result, main = "Lord's Chi-Square DIF Statistics")
5
按群体绘制被标记题目的 ICC

仅有统计标记不足以作出诊断。为每个群体分别绘制 ICC，可以直接从图上看出 DIF 的性质和大小。我们用 mirt 程序包分别拟合各群体的 2PL 模型，再提取 ICC 概率进行图形比较。

R ICC 可视化 
# Fit separate 2PL models for each group
mod_male   <- mirt(data_resp[group == 0, ], 1, itemtype = "2PL", verbose = FALSE)
mod_female <- mirt(data_resp[group == 1, ], 1, itemtype = "2PL", verbose = FALSE)

# Extract ICC probabilities for flagged Item 5
theta_seq <- seq(-3, 3, by = 0.01)
p_male    <- probtrace(extract.item(mod_male,   5), theta_seq)[, 2]
p_female  <- probtrace(extract.item(mod_female, 5), theta_seq)[, 2]

# Build tidy data frame
df_icc <- data.frame(
  theta = rep(theta_seq, 2),
  prob  = c(p_male, p_female),
  group = rep(c("Male (Reference)", "Female (Focal)"),
              each = length(theta_seq))
)

# Plot
ggplot(df_icc, aes(theta, prob, color = group)) +
  geom_line(linewidth = 1.3) +
  scale_color_manual(
    values = c("Male (Reference)" = "#032454",
               "Female (Focal)"   = "#fcc209")
  ) +
  labs(
    title    = "ICC Comparison: Item 5",
    subtitle = "Uniform DIF: female students have consistently higher P(correct)",
    x        = expression("Ability " * theta),
    y        = "P(Correct)",
    color    = NULL
  ) +
  theme_minimal(base_size = 13) +
  theme(legend.position = "top")

解释结果

统计显著并不等于实际重要。最常用的 DIF 大小分类体系由美国教育考试服务中心（ETS）提出，基于 MH D-DIF 量尺。

仅凭统计显著并不足以删除题目。C 类题目应接受实质性的专家审查，以确定功能差异的来源。有时原因可从题目内容中看出（例如带有特定文化或地域色彩的内容），有时则需要更深入的调查。统计标记是审查的开始，而不是结束。

实用提示

在 difMH() 中使用 purify = TRUE 迭代进行 DIF 分析。这会在能力匹配步骤中逐步剔除被标记的题目，防止受污染的锚题掩盖其他 DIF——这是首轮分析中常见的问题。

应用实例：生态意识工具中的性别与年级 DIF

Wiradika 和 Mahendra（2026）对一份面向小学生的生态意识工具进行了 DIF 分析。研究考察了两个分组变量：性别（男 vs 女）和年级，从而在同一工具上从多个角度评估测量公平性。

这些发现对工具开发有直接意义。涉及特定生态情境（如沿海生态系统）的题目，可能会系统性地有利于生活经验与该情境相符的学生。这种结构性偏差仅看总体分数是发现不了的；DIF 分析为识别和处理这类差异提供了方法依据。

应对 DIF：实用建议

检测只是 DIF 分析的第一步。如何应对取决于问题的严重程度和测验情境：

  1. 组织内容审查小组。来自参照组和焦点组的学科专家应检查被标记的题目，判断在群体真实能力水平之外，观察到的表现差异是否有实质性原因。
  2. 修改题干或情境。如果 DIF 来自特定情境的内容（如红树林、灌溉渠、捕鱼方式），最好改为生态上更中性的刺激材料，也可以考虑针对不同情境编制平行版本。
  3. 删除题目只是最后手段。删除题目会缩短工具长度、降低信度，修改通常更可取。如果必须删除，应将该题从题库中退役，而不只是不计分，并在后续版本中替换。
  4. 记录并报告。DIF 结果是工具效度证据的一部分。公开报告应说明哪些题目被标记、DIF 的大小和方向，以及采取的补救措施。
公平的测评并不假定各群体相同，而是确保每道题对所有受测者都一致地测量预期的构念。

结论

DIF 分析处在心理测量的严谨性与测量公平的交汇处。它要回答的核心问题——一道题是否在各群体中等价地测量预期构念——在方法上可以处理，在实质上却要求很高。Mantel-Haenszel 程序、Lord 卡方和逻辑回归从不同的统计角度回答这个问题；结合使用，它们构成了公平测验开发的有原则的框架。

对于开发或验证教育测评的研究者，无论哪个领域，都应把 DIF 分析作为工具评估的标准组成部分。difR 程序包在 R 中提供了易用的实现。但更艰难的任务在于实质性解释：弄清一道题为什么出现功能差异，并决定恰当的应对方式。
